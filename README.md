#Jogo da Forca em Python
Um jogo clássico da Forca desenvolvido em Python para execução no terminal. O jogador deve adivinhar a palavra secreta letra por letra antes que o desenho da forca seja completado.

Funcionalidades
Sorteio aleatório de palavras.
Interface simples via terminal.
Controle de letras corretas e incorretas.
Validação das entradas do usuário.
Representação gráfica da forca utilizando ASCII Art.
Opção de jogar novamente ao final da partida.

Tecnologias Utilizadas
Python 3
Biblioteca padrão random

Estrutura do Projeto
forca.py

Como Executar:
Pré-requisitos
Python 3 instalado na máquina.
Executando o programa
Clone este repositório:
git clone https://github.com/seu-usuario/seu-repositorio.git
Acesse a pasta do projeto:
cd seu-repositorio
Execute o arquivo:
python forca.py

Regras do Jogo
Uma palavra é escolhida aleatoriamente.
O jogador deve tentar adivinhar a palavra informando uma letra por vez.
Cada letra incorreta adiciona uma parte ao desenho da forca.
O jogador vence quando descobre todas as letras da palavra.
O jogador perde quando atinge o limite máximo de erros.
