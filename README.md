🎮 Jogo da Forca em Python

Este projeto consiste em uma implementação do clássico jogo da Forca desenvolvida em Python para execução via terminal. O objetivo do jogador é descobrir a palavra secreta, tentando acertar suas letras antes que o número máximo de erros seja atingido. O programa utiliza uma interface textual simples e intuitiva, tornando-o ideal para praticar conceitos fundamentais de programação.

O jogo seleciona aleatoriamente uma palavra de uma lista pré-definida e acompanha os palpites do usuário, exibindo as letras corretas, as letras incorretas e o estado atual da forca utilizando arte ASCII. Ao final de cada partida, o jogador pode optar por iniciar uma nova rodada.

Funcionalidades:
Seleção aleatória de palavras.
Controle de letras corretas e incorretas.
Validação da entrada do usuário.
Exibição gráfica da forca em ASCII Art. (Representação visual da forca utilizando caracteres de texto no terminal.)
Verificação automática de vitória ou derrota.
Opção de reiniciar o jogo sem encerrar o programa.

Tecnologias Utilizadas:
Python 3
Biblioteca padrão random

Regras do Jogo:
Uma palavra é escolhida aleatoriamente.
O jogador deve tentar adivinhar a palavra informando uma letra por vez.
Cada letra incorreta adiciona uma parte ao desenho da forca.
O jogador vence quando descobre todas as letras da palavra.
O jogador perde quando atinge o limite máximo de erros.
